# VCMalloc: A Virtually Contiguous Memory Allocator
Please refer to the papers below for more details; the benchmarks behind each of them are in [vcmalloc_bench](https://github.com/ycinhdj/vcmalloc_bench).
## Publications
- Y. Hadjadj, C. M. A. Zouaoui, N. Taleb, S. Mazari, M. El Bahri and M. Chikr El-Mezouar, “VCMalloc: A Virtually Contiguous Memory Allocator,” *IEEE Transactions on Computers*, 2023. [doi:10.1109/TC.2023.3302731](https://doi.org/10.1109/TC.2023.3302731) · benchmarks: [vcmalloc_bench](https://github.com/ycinhdj/vcmalloc_bench)
- Y. Hadjadj, C. M. A. Zouaoui and N. Taleb, “Virtually Contiguous Memory Allocation in Embedded Systems: A Performance Analysis,” *IEEE Embedded Systems Letters*, 2024. [doi:10.1109/LES.2024.3416192](https://doi.org/10.1109/LES.2024.3416192) · benchmarks: [vcmalloc_bench/rpibench](https://github.com/ycinhdj/vcmalloc_bench/tree/master/rpibench)
- C. M. A. Zouaoui, Y. Hadjadj, N. Taleb, M. El Bahri and M. R. Naimi, “Virtually Contiguous Host Allocation for Fragmentation-Resilient CPU–GPU Transfers: Performance and Energy Analysis,” *IEEE Access*, 2026.
